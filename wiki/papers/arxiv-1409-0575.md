The paper describing the ImageNet Large Scale Visual Recognition Challenge
(ILSVRC): how its datasets for image classification, single-object
localization and object detection were built, how entries are scored, and what
the 2010–2014 challenges showed. It documents the shift from hand-built feature
pipelines to convolutional neural networks, and compares the best 2014 model
with trained human annotators [src:arxiv_1409.0575 p.1].

Russakovsky, Deng, Su, Krause, Satheesh, Ma, Huang, Karpathy, Khosla, Bernstein,
Berg, Fei-Fei. *ImageNet Large Scale Visual Recognition Challenge.* arXiv:1409.0575, 2014.

## Contribution

- A benchmark run every year since 2010, with a public training set and test
  annotations kept hidden [src:arxiv_1409.0575 p.1] [src:arxiv_1409.0575 p.2].
- Three tasks: image classification (2010–2014), single-object localization
  (2011–2014) and object detection (2013–2014) [src:arxiv_1409.0575 p.4].
- Crowdsourcing methods for labelling at a scale where a small team of
  annotators is no longer feasible, going from 20 classes in PASCAL VOC to 1000
  [src:arxiv_1409.0575 p.2].
- An analysis of what the winning methods got right and wrong, and a
  comparison with human accuracy [src:arxiv_1409.0575 p.2].

## Method (dataset and evaluation)

- **Source images.** ILSVRC is a subset of ImageNet, which organizes images by
  WordNet synsets; as of August 2014 ImageNet had 14,197,122 images in 21,841
  synsets [src:arxiv_1409.0575 p.2].
- **Classification data.** 1000 classes, about 1.2 million training images,
  50 thousand validation and 100 thousand test images [src:arxiv_1409.0575 p.8].
  Candidate images come from search engines and are checked by several Amazon
  Mechanical Turk workers, with the number of votes needed set per category
  [src:arxiv_1409.0575 p.7].
- **Label quality.** About 99.7% precision; a manual check of 1500 test images
  found 5 errors [src:arxiv_1409.0575 p.7].
- **Detection data.** 200 classes; for 2014, 456,567 training images and
  40,152 test images [src:arxiv_1409.0575 p.15].
- **Top-5 error.** Each image has one ground-truth label, but may contain other
  objects, so a prediction counts as correct if any of 5 returned labels
  matches. Top-1 and hierarchical error gave the same ranking, so only top-5
  has been used since 2012 [src:arxiv_1409.0575 p.15].
- **Localization.** A label also needs a box overlapping the ground truth with
  intersection over union above 0.5 [src:arxiv_1409.0575 p.15].
- **Significance.** Confidence intervals come from bootstrap resampling of the
  test set [src:arxiv_1409.0575 p.23].

## Results

- **The 2012 shift.** SuperVision (Krizhevsky et al.) won classification and
  localization with a deep convolutional network of 60 million parameters,
  trained on GPUs with dropout [src:arxiv_1409.0575 p.18]. Its top-5 error was
  16.4% [src:arxiv_1409.0575 p.19], or 15.3% with outside data
  [src:arxiv_1409.0575 p.24]. By 2014 all top entries relied heavily on
  convolutional networks [src:arxiv_1409.0575 p.22].
- **Classification error over five years.** Fell 4.2× (28.2% → 6.7%), and
  localization error fell 1.7× (42.5% → 25.3%), counting only entries that used
  the provided data [src:arxiv_1409.0575 p.22].
- **2014 winners.** GoogLeNet won classification
  ([[arxiv-1409-4842]]), and VGG won localization using networks of up to 19
  weight layers ([[arxiv-1409-1556]]) [src:arxiv_1409.0575 p.22].
- **Detection.** mAP rose from 22.6% (2013) to 43.9% (2014). The authors
  credit most of this to new algorithms, since more training data accounts for
  only about 1–4 points of absolute mAP [src:arxiv_1409.0575 p.23].
- **Statistical significance.** The winners differ significantly from other
  entries even at the 99.9% level [src:arxiv_1409.0575 p.23].
- **Human comparison.** A trained annotator had 5.1% top-5 error on 1500 test
  images, against an estimated 6.8% for GoogLeNet on the same images
  (p = 0.022). A less-trained annotator had 12.0% error on 258 images
  [src:arxiv_1409.0575 p.31]. Many human errors come from fine-grained classes
  (37% of errors, against 7% for GoogLeNet) and from not knowing a class exists
  (24%) [src:arxiv_1409.0575 p.33].

## Limitations

- Each classification image has only one ground-truth label, which is why the
  metric is top-5 [src:arxiv_1409.0575 p.15].
- 3.5% of localization images were discarded because instances could not be
  delineated, for example bunches of bananas [src:arxiv_1409.0575 p.15].
- The authors answer three criticisms: objects tend to be large and centred;
  fine-grained classes cause most of the remaining label errors; and the
  outside-data rules are unclear, which led to separate "provided" and
  "outside" data tracks in 2014 [src:arxiv_1409.0575 p.33]
  [src:arxiv_1409.0575 p.34].
