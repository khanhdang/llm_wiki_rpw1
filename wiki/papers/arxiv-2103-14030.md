Swin Transformer is a hierarchical vision Transformer meant as a
general-purpose backbone. It computes self-attention inside non-overlapping
local windows and shifts the windows between consecutive layers so that
information crosses window borders. Its cost is linear in image size, and it
produces multi-scale feature maps like a CNN, so it works for detection and
segmentation as well as classification [src:arxiv_2103.14030 p.1].

Liu, Lin, Cao, Hu, Wei, Zhang, Lin, Guo. *Swin Transformer: Hierarchical Vision
Transformer using Shifted Windows.* arXiv:2103.14030, 2021.

## Contribution

- **Two gaps between language and vision.** Visual entities vary widely in
  scale, and images have far more pixels than a text has words. Fixed-scale
  tokens and global attention suit neither [src:arxiv_2103.14030 p.1].
- **[[shifted-window-attention]].** Windows shift between layers to give
  cross-window connections. All queries in a window share one key set, so
  memory access is efficient and latency far lower than with sliding windows
  [src:arxiv_2103.14030 p.2].
- **A hierarchical backbone.** Feature maps at strides 4, 8, 16 and 32, the
  same resolutions as typical CNNs [src:arxiv_2103.14030 p.3].

## Method

- **Patch embedding.** 4×4 patches, giving 48-dimensional raw features, are
  linearly embedded to C channels [src:arxiv_2103.14030 p.3].
- **Patch merging.** Each 2×2 group of neighbouring patches is concatenated
  and projected from 4C to 2C, halving the resolution at each of stages 2–4
  [src:arxiv_2103.14030 p.3].
- **Swin block.** The standard multi-head self-attention module is replaced
  with window-based attention (W-MSA, or SW-MSA in shifted layers), followed by
  a 2-layer MLP with GELU. LayerNorm comes before each module and a residual
  connection after it [src:arxiv_2103.14030 p.4].
- **Window attention.** Windows of M×M patches (M = 7 by default) make the
  cost linear in the number of patches, where global attention is quadratic.
  Alternate layers shift the windows by ⌊M/2⌋ [src:arxiv_2103.14030 p.4].
- **Cyclic shift.** Shifted windows are computed in a batch by cyclically
  shifting the feature map and masking attention. This avoids padding,
  which would cost 2.25× for 2×2 windows [src:arxiv_2103.14030 p.5].
- **Relative position bias.** Each head adds a relative position bias B to
  its attention scores. Also adding ViT-style absolute embeddings slightly
  hurts [src:arxiv_2103.14030 p.5].
- **Variants.** Swin-T (C = 96, layers {2, 2, 6, 2}), Swin-S (96,
  {2, 2, 18, 2}), Swin-B (128, {2, 2, 18, 2}) and Swin-L (192,
  {2, 2, 18, 2}). Swin-T and Swin-S cost about the same as ResNet-50 and
  ResNet-101 [src:arxiv_2103.14030 p.5].
- **Training.** AdamW for 300 epochs on ImageNet-1K, mostly following DeiT
  [src:arxiv_2103.14030 p.5] [src:arxiv_2103.14030 p.6].

## Results

- **ImageNet-1K training.** Swin-T scores 81.3%, against 79.8% for DeiT-S
  [src:arxiv_2103.14030 p.6]. Its speed-accuracy trade-off is slightly better
  than RegNet and EfficientNet [src:arxiv_2103.14030 p.6].
- **ImageNet-22K pre-training.** Swin-B reaches 86.4%, 2.4 points above ViT at
  similar throughput, and Swin-L reaches 87.3% [src:arxiv_2103.14030 p.6].
- **COCO.** Swin-T gains 3.4–4.2 box AP over ResNet-50 across four detection
  frameworks. With HTC++, Swin-L reaches 58.7 box AP and 51.1 mask AP on
  test-dev, +2.7 and +2.6 above the previous best [src:arxiv_2103.14030 p.7].
- **ADE20K.** Swin-L reaches 53.5 mIoU on val, +3.2 over SETR. Swin-S scores
  49.3 against 44.0 for DeiT-S [src:arxiv_2103.14030 p.8].
- **Ablations (Swin-T).** Shifted windows add +1.1% top-1 on ImageNet,
  +2.8/+2.2 box/mask AP on COCO and +2.8 mIoU on ADE20K over windows that
  never shift [src:arxiv_2103.14030 p.8].
- **Speed.** Shifted-window models are 4.1/1.5×, 4.0/1.5× and 3.6/1.5× faster
  than sliding-window variants (naive/kernel implementations) for T, S and B,
  with similar accuracy [src:arxiv_2103.14030 p.8].
- **Translation invariance.** The authors conclude that an inductive bias
  toward translation invariance is still preferable for general-purpose
  vision, especially dense prediction [src:arxiv_2103.14030 p.8].

## Limitations

- **Implementation speed.** Swin uses built-in PyTorch functions rather than
  cuDNN-optimized kernels, and kernel optimization is out of scope
  [src:arxiv_2103.14030 p.7].
- **Comparing with DeiT.** DeiT produces a single resolution, so deconvolution
  layers had to be added to use it for detection [src:arxiv_2103.14030 p.6].
